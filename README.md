# Håkan Karlsson

An English-language personal entrance page. Four fields and three activities are connected by a short raven animation.

Open index.html, or serve this folder using any static web server. No build step, external font calls, tracking or cookies. The semantic text is present without JavaScript. Reduced motion shows a still network. Replay and tab visibility changes stop the previous flight.

Liberation Serif is bundled with its license in assets/FONT-LICENSE.txt. The uppercase name follows the requested business-card typography.

GitHub Pages: main, root. No custom domain or CNAME.

This is a prototype: field labels are an editorial design choice, not verified credentials.
